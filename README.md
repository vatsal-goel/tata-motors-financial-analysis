# Tata Motors Financial Performance & Business Health Analysis

## Project Overview
This project analyzes Tata Motors' financial performance using multi-year financial statements, financial ratios, business health indicators, and dashboard-based insights.

## Objective
To evaluate Tata Motors' profitability, liquidity, solvency, cash flow strength, and overall business health using Python, SQL, Excel, and Power BI.

## Tools Used
- Python
- Pandas
- SQL
- Microsoft Excel
- Power BI
- GitHub

## Current Project Status
Project setup completed. Raw annual reports and FY25 result files have been collected locally. Data extraction and cleaning will be performed in the next phase.

## Data Sources
- Tata Motors Integrated Annual Reports FY2020-21 to FY2024-25
- Q4 FY25 Financial Results
- Q4 FY25 Investor Presentation
- Q4 FY25 Results Press Release
- FY25 Segment-wise Financial Snapshot

## Planned Analysis
- Revenue and profitability trend
- Expense and margin analysis
- Liquidity analysis
- Solvency and debt analysis
- Cash flow analysis
- Segment-wise performance analysis
- Business health scorecard
- Management recommendations
